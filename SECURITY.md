# Security policy

This prototype is not suitable for real mail or credentials. No supported production versions exist yet.

Use the repository's private vulnerability reporting / security advisory feature if enabled. If unavailable, ask the owner for a private reporting channel without disclosing vulnerability details. Do not open public issues containing secrets, message content, or exploitable details. Maintainers should acknowledge private reports within seven days; this is a target, not a guaranteed response SLA.

See docs/SECURITY_DESIGN.md for planned controls. Hosting the demo server publicly is unsupported.
